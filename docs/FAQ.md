# 常见问题

## 改之前

**会不会把游戏弄坏？**
不会改 exe、不注入进程，只复制 Content 下的资源文件。第一次改动前会自动做全量快照，
出问题点「还原原始」即可。实在不放心，先手动把 `Content` 目录复制一份。

**需要退出游戏吗？**
需要。资源在启动/进关时加载，运行中改文件不生效，还可能被占用写不进去。

**启动时弹「放错位置了」怎么办？**
工具要和 Lawn.exe 放在同一个文件夹（游戏根目录），它要读同级的 Content。
点「取消」退出，把 exe 挪过去再开；点「确定」也能进，但要自己在顶栏把游戏目录填对。

**为什么有的植物没有立绘预览？**
只有 38 个植物带 Spine 骨骼（spanim/*.skel）。其余植物只有 reanim 帧动画，
会走 reanim 预览；再没有就退回静态原画。

**为什么植物列表里有「香蒲·2」这种？**
同一个植物的不同形态（立绘部件、弹道、皮肤）是不同文件，名字后面带后缀。
以别的植物 key 为前缀的都是附属资源，已经在列表里剔掉了。

## 预览

**预览里为什么和游戏里不一样大小？**
预览是按面板高度自适应的，不同植物的模型单位尺度差很多。两边看起来应该差不多高，
如果想比较真实比例，把缩放调成一致（或看原画）。

**为什么点「重新载入」后缩放回 1.00x？**
预览对象是重建的。这是已知行为，缩放会回到默认。

**僵尸的「配件」是什么？**
路障、铁桶、旗子、纱门、鸭子圈、水花、胡子、梯子、读报这些挂在僵尸身上的东西。
默认不显示（裸僵尸），选一套就只显示那一套。

**旗子/纱门为什么需要特殊处理？**
它们是**独立的 reanim 文件**（例如旗子在 `Zombie_flagpole.xnb`），不在 Zombie.xnb 里。
预览要把配件按主体骨骼的世界矩阵挂上去，同时把主体里与之冲突的手臂轨道藏掉。

**有的僵尸选了是空的？**
少数 reanim 只有占位轨道（Caltrop / Chomper / ZombiesWon / menu_crow），没有可绘制的帧。

## 修改

**替换和互换有什么区别？**
替换是单向覆盖：B 变成 A 的样子，A 不变。
互换是双向对调：两边都变成对方。

**哪些文件会跟着一起换？**
勾选哪些目录就处理哪些。默认 spanim + reanim + particles + sounds + voices，
images 一般不勾（那是图鉴/卡片的贴图，换多了容易乱）。

**交换后图鉴卡片没变？**
卡片缩略图在 `images/600x1000` 里，勾上 images 再操作一次。

**声音/语音换错了怎么单独还原？**
勾选目录只保留 sounds/voices 再点「还原原始」，或直接从备份目录里挑文件复制回去。

## Mod

**「作品」是什么？**
一份从游戏里导出的资源副本（含 mod.json 描述），可以直接改里面的 png，也可以发给别人导入。
存放在 `<游戏目录>/资源修改器/Mod/<中文名>_<key>/`。

**导入会不会把游戏搞乱？**
导入是按相对路径覆盖写回 Content，导入前会自动备份。作品里多余的文件也会被一并写入，
所以别把无关文件塞进作品目录。

## 构建

**自己编译报找不到 Spine？**
Spine 运行时不能随仓库分发，需要自己编译 4.2 分支。见 [BUILD.md](BUILD.md)。

**为什么要 4.2 的运行时？**
游戏资源是 Spine 4.2.43 导出的，旧版运行时会解析失败（通常表现为 IndexOutOfRange）。

## 配置

**配置存在哪？**
`<游戏目录>/资源修改器/资源修改器.ini`，纯文本可手改。
每个模式的选择、缩放、列表范围都在里面，正常退出时写回。

**怎么恢复出厂设置？**
删掉 `资源修改器.ini` 即可（备份和 Mod 不会被删）。

**强杀进程会保存配置吗？**
不会。需要正常关闭窗口（点 X 或 Alt+F4）才会写 ini。
